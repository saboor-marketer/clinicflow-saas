# ClinicFlow — Appointment Management SaaS

A frontend-only SaaS dashboard recreated from the supplied Medcare/ClinicFlow reference design.

## Stack
- HTML5
- CSS3
- JavaScript ES6+
- Bootstrap 5.3
- Bootstrap Icons

## Included
- Responsive dashboard layout
- Sidebar navigation
- KPI cards
- Revenue and patient-arrival visualizations using inline SVG/CSS
- Appointment table
- Doctor availability panel
- Search and filtering
- Date selection
- CSV export
- Generate-report interaction
- Light/dark theme toggle
- Mobile sidebar

## Run
Open `index.html` in a browser. An internet connection is only needed for the Bootstrap, Bootstrap Icons and Google Fonts CDN assets.
